워크샵 개요

Amazon Bedrock에서 동작하는 AI 코딩 에이전트 Claude Code를 하루 동안 직접 설치하고 사용해 보는 실습 워크샵입니다. 설치부터 자동화, 팀 설정, SDK 활용까지 실무에 바로 적용할 수 있는 내용을 다룹니다.

진행 방식 — AWS Workshop Studio 플랫폼을 사용합니다. 참가자에게 실습용 AWS 계정과 개발 환경이 자동으로 제공되므로, 노트북과 웹 브라우저(Chrome 권장)만 준비하시면 됩니다. 실습 진행은 AWS 담당자가 맡으며, 화면의 가이드를 따라 함께 진행합니다.
